# Исправленная версия сайта Дарьи Йылдыз

Размещение фото:
- Главный экран: портрет в помещении (portrait.jpg).
- Второй блок «Обо мне»: фото в беседке (gazebo.jpg).
- Раздел «Вне учёбы», танцы: танцевальная пара и чёрное платье (dance-pair.jpg, dance-dress.jpg).

Откройте index.html после распаковки; оставьте assets рядом. Для публикации загрузите содержимое папки в корень репозитория и включите GitHub Pages из ветки main, /(root).

Сайт остаётся одностраничным: «вторая страница» понята как второй блок «Обо мне» исходного концепта, не отдельный URL.
Проверено в Chromium: 320, 375, 390, 650, 768, 1024, 1440, 1920 px. Нет горизонтального переполнения, текст не выходит за экран, имя не пересекается с фото. Все фотографии декодируются. Другие браузеры не проверялись.

assets/site.css — адаптивная вёрстка; assets/site.js — мобильное меню; index.html — тексты. Manrope локальный, лицензия FONT-LICENSE.txt. Playfair не был встроен в концепт: применяется системный serif-fallback.

Важно: assets/resume.pdf — исходное резюме с номером телефона. При необходимости замените перед публичной публикацией.
